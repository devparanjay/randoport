# randoport

A modern, fast website allowing developers, testers, and operators to quickly find safe, non-conflicting network ports for their applications.

## Features
- Generate random port numbers from safe ranges (Registered and Ephemeral).
- Bypasses well-known and commonly used registered ports.
- Allows specifying the number of ports needed.
- Beautiful, dark, futuristic "Cyber-Minimalist" UI.
- One-click copy functionality.

## Tech Stack
- Next.js (App Router)
- React
- Tailwind CSS
- Lucide React (Icons)

## Getting Started

1. Navigate to the project directory:
   \`\`\`bash
   cd randoport
   \`\`\`
2. Install dependencies:
   \`\`\`bash
   npm install
   \`\`\`
3. Run the development server:
   \`\`\`bash
   npm run dev &
   \`\`\`
4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
